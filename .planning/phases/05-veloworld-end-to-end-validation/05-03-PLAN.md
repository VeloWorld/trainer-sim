<!-- The contract for handling CI failures during this plan -->

When `gh pr checks <PR>` reports a failed leg:

1. Click into the failing job's logs (`gh run view <run-id> --log-failed`).
2. Classify the failure:

   **VW-side failure (most common)**:
   - Typecheck error in adapter or test
   - Test assertion failure
   - Build error
   - Bundle-grep gate hit (trainer-sim leak into prod bundle)
   - macOS-specific install/build failure (electron, native bindings)

   Fix locally in VW: edit, `pnpm typecheck && pnpm test && pnpm --filter @veloworld/desktop build`, commit on the feature branch, `git push --force-with-lease`. CI re-runs. Loop until green.

   **trainer-sim contract gap (rare, but the D-VW-08 one-way door)**:
   - "Cannot find module 'trainer-sim'" → `prepare` hook didn't fire (Plan 05-01 bug; surface to human)
   - `createFakeTransport(...)` throws on a valid input → trainer-sim Phase 4 bug
   - DataView shape diverges from spec → trainer-sim Phase 1 bug
   - `FitLoadError` family doesn't bubble correctly → trainer-sim Phase 2 bug
   - Pause/resume disconnect/reconnect re-parse races → trainer-sim Phase 3/4 bug

   STOP this plan. Escalate to user with the diagnosis. The user authorizes a "Wave 0.5" trainer-sim source fix:
   - New trainer-sim commit lands on `main` (similar shape to Plan 05-01 but a real source fix in `src/`).
   - Capture the new sha; rewrite `05-WAVE-0-SHA.txt` with the new sha.
   - Back in VW: edit `apps/desktop/package.json` to repin the new sha, `pnpm install` to regen lockfile, `git commit --amend` (or new commit; user picks), `git push --force-with-lease`.
   - CI re-runs. Loop until green.
   - The Wave 0.5 fix gets recorded in Plan 05-04's narrative per D-VW-09 item 5.

   **Anti-pattern**: Widening trainer-sim's `ITrainerTransport` to absorb a VW shape that doesn't conform. Forbidden by Anti-Pattern 6 + user override #1. If the failure looks like "trainer-sim doesn't have method X that VW needs," the fix is VW-side (the adapter implements X locally), NOT trainer-sim-side.

3. Iteration budget: If 5+ iteration cycles fail to drive CI green, surface to human for re-evaluation. Could indicate a fundamental design issue requiring CONTEXT.md amendment or a phase-split.
