| trainer-sim source -> consumer install (npm/pnpm) | The `prepare` lifecycle hook runs in the consumer's environment with whatever `node`/`npm`/`pnpm` they have. | Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01-01 | Tampering | `package.json` `prepare` script body | accept | The script body is the literal string `npm run build`. A malicious replacement would require write access to the repo's `package.json`, which is the same trust level as modifying any other source file. Standard repo hygiene (PR review, branch protection on `main`) is the existing mitigation; Phase 5 doesn't introduce new attack surface. |
| T-05-01-02 | Denial of Service | `prepare` hook on every consumer install | accept | RESEARCH §A8 quantified the cost: ~1 second per fresh install (tsup is sub-second). Trainer-sim's CI doubles its build (`npm ci` runs `prepare`, then the explicit `npm run build` step runs again). Acceptable per RESEARCH recommendation — doubled-build is more readable than relying solely on the implicit `prepare` hook. No DoS vector against external consumers (they pay the cost once per `pnpm install`, then the cached build is reused). |
| T-05-01-03 | Information Disclosure | git-ref install path leaks trainer-sim's full git history into VW's `node_modules` | mitigate | npm/pnpm git-ref installs clone the source tree at the pinned sha. The clone includes `.git/` which leaks history. Mitigation: VW's `node_modules` is gitignored on the VW side (standard); the leak is local to the consumer's machine. trainer-sim is MIT-licensed and public on GitHub anyway, so the "leak" is non-secret. No action required in Wave 0; Wave 1 inherits the same disposition. |
| T-05-01-04 | Repudiation | The Wave 0 sha capture step | mitigate | The captured sha is recorded both in `05-WAVE-0-SHA.txt` (committed) AND used in the Wave 0 commit message preamble. Tampering would require simultaneously rewriting the file, the commit, and the Wave 1 PR — visible in code review. |
| T-05-01-05 | Elevation of Privilege | `prepare` script runs arbitrary `npm run build` on every consumer install | accept | The build script is `tsup`, a well-known TypeScript bundler. The risk is identical to publishing the same code via `npm publish` — the consumer runs the producer's build code in either case. trainer-sim's MIT license and public repo make this transparent. No mitigation beyond standard hygiene. |
