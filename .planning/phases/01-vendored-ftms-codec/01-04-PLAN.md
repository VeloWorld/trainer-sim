       - Payload 5 (speed-present): `{power: 100, cadence: 60, speed: 30}` → `Uint8Array([0x44, 0x00, 0xB8, 0x0B, 0x78, 0x00, 0x64, 0x00])` (8 bytes)
       Each test uses `new Uint8Array(view.buffer, view.byteOffset, view.byteLength)` to extract actual bytes from the returned DataView, then `expect(actual).toEqual(expected)`.

    2. **Round-trip suite (FTMS-05a, FTMS-02, FTMS-03)** — `it.each` over sint16/half-rpm parametrized cases:
       - `{power: 200, cadence: 90, label: 'typical'}`
       - `{power: -1, cadence: 0.5, label: 'sint16 -1, half-rpm 0.5'}`
       - `{power: 32767, cadence: 90.5, label: 'sint16 max + half-rpm'}`
       - `{power: -32768, cadence: 0, label: 'sint16 min'}`
       - `{power: 0, cadence: 60, label: 'zero power'}`
       Each: encode → decode via `decodeIndoorBikeData` from `test/fixtures/ftms-decoder` → assert `decoded.power === power` AND `decoded.cadence === cadence` AND `decoded.speed === undefined`.

    3. **Bit-0 inversion suite — both branches (FTMS-04, D-06)** — three explicit tests:
       - "sets bit 0 = 1 when speed is omitted (more data NOT present)": encode `{power: 100, cadence: 60}`, read flags via `view.getUint16(0, true)`, assert `(flags & 0b1) === 1`.
       - "sets bit 0 = 0 when speed IS present (inversion: 0 means present)": encode `{power: 100, cadence: 60, speed: 30}`, read flags, assert `(flags & 0b1) === 0`.
       - "round-trips speed-present payload": encode `{power: 100, cadence: 60, speed: 30}`, decode, assert `decoded.speed` is approximately 30 (use `toBeCloseTo(30, 2)` for FP tolerance), `decoded.cadence === 60`, `decoded.power === 100`.

    4. **FIELDS source-of-truth suite (D-09)** — three explicit assertions to catch silent FIELDS mutation:
       - "declares power as sint16 (NOT uint16 — Auuki bug check)": `expect(FIELDS.instantaneousPower.type).toBe('sint16')`.
       - "declares cadence resolution as 0.5 rpm": `expect(FIELDS.instantaneousCadence.resolution).toBe(0.5)`.
       - "declares speed bit-0 as inverted": `expect(FIELDS.instantaneousSpeed.flagBit).toBe(0)` AND `expect(FIELDS.instantaneousSpeed.inverted).toBe(true)`.

    5. **Endianness sanity check (PITFALLS.md #4)** — one test reading raw bytes:
       - Encode `{power: 200, cadence: 90}` (Payload 1).
       - Read `view.getUint16(2, true)` → 180 (cadence wire); read `view.getUint16(2, false)` → 0xB400 = 46080 (the BE-default disaster value).
       - Assert `view.getUint16(2, true) === 180` AND `view.getUint16(2, false) === 46080`.
       - This single assertion makes the LE-vs-BE invariant impossible to silently violate.
