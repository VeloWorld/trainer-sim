## Shared Patterns

### Cross-repo git-ref + `prepare` hook contract

**Source:** trainer-sim's `package.json` (after Wave 0); npm CLI documentation (https://docs.npmjs.com/cli/v10/using-npm/scripts).
**Apply to:** Wave 0 (trainer-sim `package.json`) AND Wave 1 (`apps/desktop/package.json` git-ref string).
**Pattern:** Producer adds `"prepare": "npm run build"` so consumer-side `pnpm install github:VeloWorld/trainer-sim#<sha>` materializes `dist/`. RESEARCH.md Pattern 2 supplies the smoke-test recipe.

### `import type` for trainer-sim type symbols

**Source:** RESEARCH.md Pitfall 3; verified across VW's existing call sites.
**Apply to:** the rewritten `apps/desktop/src/renderer/src/lib/dev/fake-trainer-transport.ts` (Wave 1).
**Pattern:** trainer-sim has `verbatimModuleSyntax: true`; VW's tsconfig does not, but VW's pattern is consistent. New imports must be:
```typescript
import { createFakeTransport, type FakeTransport } from 'trainer-sim';
// or
import type { ITrainerTransport } from 'trainer-sim';
```
NOT `import { ITrainerTransport } from 'trainer-sim'` (would fail at bundle time because trainer-sim's `dist/index.{js,cjs}` strips type-only exports).

### Renderer-process safety: use `{ buffer: Uint8Array }` source variant only

**Source:** RESEARCH.md Pitfall 6.
**Apply to:** `apps/desktop/src/renderer/src/lib/dev/fake-trainer-transport.ts` (Wave 1) — the `connect()` body's `createFakeTransport({...})` call.
**Pattern:**
```typescript
const bytes = await window.veloworld.dev.readFitFile();   // returns Uint8Array
this.inner = createFakeTransport({ source: { buffer: bytes } });
// NOT: { source: { path: '...' } }  — node:fs unavailable in Electron renderer
```

### CI matrix expansion (single-job, cross-OS)

**Source:** trainer-sim's `.github/workflows/ci.yml` (already implements `[ubuntu-latest, macos-latest]` with `fail-fast: false`); RESEARCH.md Code Examples §4.
**Apply to:** `veloworld-ride/.github/workflows/ci.yml` Wave 1 edit.
**Pattern:** prefer single job with `strategy.matrix.os` over duplicated job declarations. `fail-fast: false` ensures a macOS failure doesn't mask Linux (mirrors trainer-sim's posture).

### Adapter-keeps-extras pattern (Anti-Pattern 6 compliance)

**Source:** ARCHITECTURE.md Anti-Pattern 6; RESEARCH.md Pattern 1.
**Apply to:** the rewritten `fake-trainer-transport.ts` (Wave 1).
**Principle:** trainer-sim's 4-method `ITrainerTransport` is the canonical core. The 5 BLE-shaped extras (`scan`, `probeControlPointSupport`, `requestControl`, `setGradeSimulation`, `releaseControl`, `reconnect`) stay VW-owned. The class implements VW's 9-method interface (from `@veloworld/ble`) and **composes** trainer-sim's `FakeTransport` internally. trainer-sim's contract does NOT widen.
