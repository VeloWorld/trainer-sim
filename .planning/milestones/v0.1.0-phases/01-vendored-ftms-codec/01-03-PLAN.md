<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Encoder input (record) ← caller | Caller provides power/cadence/optional speed; encoder must not crash on edge values |
| Encoder output (DataView) → consumer | DataView wraps a Buffer's ArrayBuffer — consumer can mutate the underlying memory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-09 | Tampering | Returned DataView aliases caller-mutable memory | accept | The encoder allocates a fresh Buffer per call (D-08) and returns a DataView over it. Callers who mutate the DataView mutate only their own copy, not shared state. Standard JS pattern; documented behavior. |
| T-01-10 | Denial of Service | Encoder receives NaN/undefined power or cadence | accept (deferred to Phase 2/3) | PITFALLS.md #6 acknowledges that v1 callers (Phase 3 replay) will pass real numbers; defensive validation deferred. Phase 2 (FIT loader) and Phase 3 (replay) are responsible for non-NaN inputs. Adding RangeError throws here is defensive depth — out of scope for this phase per Pitfall 6 "[ASSUMED]" note. |
| T-01-11 | Tampering | FIELDS table mutability | mitigate | `FIELDS = { ... } as const` makes the type readonly; runtime mutation throws TypeError under strict mode. Plan 04 asserts FIELDS values directly to catch silent mutation. |
| T-01-12 | Information Disclosure | DataView shares ArrayBuffer with original Buffer | accept | Standard zero-copy pattern; any consumer holding the DataView already holds the bytes. No PII in FTMS payloads (only power/cadence/speed numbers). |
| T-01-13 | Spoofing | Hard-coded flag bytes bypass inversion logic | mitigate | D-05 forbids hard-coded flag literals; acceptance criteria grep-bans them. Plan 04 round-trip tests both bit-0 branches as a behavioral check. |

Pure encoder, no I/O, no network, no untrusted parsing. ASVS L1 V5 (input validation) is the only category remotely applicable; deferred to upstream layers per the architecture seam.
</threat_model>
