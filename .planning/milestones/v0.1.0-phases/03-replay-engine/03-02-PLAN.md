<objective>
Wave 2 of Phase 3: ship the `Replay` class — the lifecycle wrapper around
`runScheduler` that Phase 4's `createFakeTransport` will instantiate. The class
adds three things the pure scheduler does not:

1. **A subscriber slot** — single subscriber per instance (D-REPL-11);
   Phase 4 wraps for fan-out.
2. **An internal AbortController** — `stop()` calls `controller.abort()`,
   composed with an optional external `signal` via `AbortSignal.any` so
   either source cancels the scheduler (RESEARCH §Open Question 3).
3. **A `completed: Promise<void>` surface** — resolves on stop-at-end
   (REPL-05); rejects with `signal.reason ?? AbortError` on cancellation
   (D-REPL-08, RESEARCH §Open Question 2).

Implements:
- REPL-05 — `replay.completed` Promise resolves on stop-at-end (Phase 4 will
  wire `EventEmitter#emit('complete')` onto Promise resolution per D-REPL-08).
- REPL-06 — `stop()` cancels the scheduler; the "no callbacks fire after
  stop" guarantee is verified end-to-end in plan 03-03's abort.test.ts.

Honors locked decisions:
- D-REPL-07 (stop-at-end → done; subsequent start() throws — single-use,
  RESEARCH §Open Question 1)
- D-REPL-08 (Promise-first completion — Phase 3 returns the Promise; Phase 4
  wires the EventEmitter)
- D-REPL-09 (AbortController cancellation; external + internal composition)
- D-REPL-10 (no emissions after abort — verified in 03-03 abort.test.ts)
- D-REPL-11 (single subscriber; Phase 4 fans out)
- D-REPL-12 (NO export from src/index.ts in this phase)
- D-REPL-13 (this file is the wrapper class layer)

Resolved open questions (per RESEARCH §Open Questions, baked in here):
1. **Restart-after-stop:** THROW. Replay instances are single-use. Phase 4's
   `reset()` (API-06) constructs a fresh `Replay` internally — that's the
   reusable surface, not Replay itself. Keeps the state machine maximally
   simple: idle → running → (done | aborted).
2. **Abort error semantics:** REJECT with `signal.reason ?? signal.reason`
   from the underlying `node:timers/promises` rejection (which is an
   `AbortError`). Matches `fetch` AbortController convention.
3. **Cursor / elapsedMs accessors:** NOT exposed. Plan 03-03 tests use the
   subscriber callback to observe emission timestamps — no accessor needed.
   YAGNI per CLAUDE.md.

Purpose: Wave 2 closes the public-to-Phase-4 surface. After this plan, plan
03-03's tests can `new Replay({ records, ... })`, `replay.onRecord(...)`,
`replay.start()`, `await replay.completed`, and `replay.stop()` — the
interface is complete.

Output: One TypeScript file (~80-110 lines), no public surface change,
`npm run build` and `npm run typecheck:test` still green.
</objective>
