    9. Internal factory `function makeFitFileParserSource(): FitRecordSource` — wraps `FitParser` with the sync-callback property:

         parse(buffer) {

           let firstError: string | undefined;

             else if (data && parsed === undefined) parsed = data;

         },
       };

        - The function is sync — no `async`, no `await`, no Promise wrapper. Plan 02-04 will assert `!(result instanceof Promise)`.
